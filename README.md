# N.P Pomboo website

## Logo

The supplied dolphin logo has been extracted from its presentation background and recolored to match the website's navy and blue palette. The header and footer use `images/np-pomboo-symbol.png`; the complete transparent logo is `images/np-pomboo-logo.png`.

## Change any picture

The artwork in Home, About, and Services can be replaced with your own photos. Gallery photos can also be replaced. No design editing is needed:

1. Open the website folder and open its `images` folder.
2. Add your photo and give it the matching filename below.
3. Keep `index.html`, `styles.css`, `script.js`, and the `images` folder together.
4. Upload the changed image(s) to your website hosting, replacing the old copy. Refresh the site to see your changes.

| Picture area | Filename |
| --- | --- |
| Home hero pool | `hero-pool.jpg` |
| About section | `about-pool.jpg` |
| Pool products service | `service-products.jpg` |
| Swimming lessons service | `service-lessons.jpg` |
| Cleaning service | `service-cleaning.jpg` |
| Equipment service | `service-equipment.jpg` |
| Gallery: pool | `pool-afternoon.jpg` |
| Gallery: lessons | `swimming-lessons.jpg` |
| Gallery: cleaning | `pool-cleaning.jpg` |
| Gallery: products | `pool-products.jpg` |

To change a photo later, replace the image in `images` with a new one using the same filename. The original illustrations remain visible if an optional photo has not been added. JPG photos are easiest. For PNG images, change `.jpg` to `.png` in `styles.css` for Home, About, and Services, and in `index.html` for Gallery.

## Preview and publish

Open `index.html` in a modern web browser to preview. Upload the contents of this folder to your static web hosting. The contact form prepares a WhatsApp message and lets visitors choose one of the three listed phone numbers; it does not need an email address or server.

Colors and mobile layout are in `styles.css`. Menu, reveal animation, and WhatsApp behavior are in `script.js`.
